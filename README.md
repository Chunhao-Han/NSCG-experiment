# Reproducibility Code for “Non-convex Stochastic Compositional Optimization Under Heavy-Tailed Noise”. Short URL: https://optimization-online.org/?p=33308

The code implements the proposed **NSCG-M** and **NSCG-S** methods and compares them with several stochastic compositional optimization baselines under heavy-tailed noise.

The repository contains two groups of experiments:

1. a synthetic policy-evaluation Markov decision process (MDP) with symmetric alpha-stable and Pareto rewards; and
2. a bistatic radar localization experiment with impulsive measurement noise.

## Requirements

The code was tested with the following configuration:

- **MATLAB:** R2018a
- **Operating system:** Windows
- **CPU:** Intel Core i7-13700
- **Memory:** 16 GB RAM


## Repository structure

| File | Description |
|---|---|
| `main_MDP.m` | Main heavy-tailed MDP experiment. It compares ASC-PG, CIVR, SCSC, MVRC, Clipped-SCG, NSCG-M, and NSCG-S. |
| `sensitivity_tail_index.m` | Builds the tail-index sensitivity figures for NSCG-M and NSCG-S from the `.mat` files generated by `main_MDP.m`. It does not rerun the algorithms. |
| `sensitivity_batch_size.m` | Batch-size sensitivity experiment for NSCG-M and NSCG-S under symmetric alpha-stable noise with tail index 1.5. |
| `sensitivity_stepsize.m` | Step-size sensitivity experiment for NSCG-M and NSCG-S under symmetric alpha-stable noise with tail index 1.5. |
| `main_radar_synthetic.m` | Bistatic radar localization experiment under symmetric alpha-stable measurement noise. |

`main_MDP.m` creates six case-specific result files in `results_minimal`, and `sensitivity_tail_index.m` reads these existing files to assemble the tail-index sensitivity plots.

### Algorithms

The main experiment compares:

- ASC-PG
- CIVR
- SCSC
- MVRC
- Clipped-SCG
- NSCG-M
- NSCG-S

The exact hyperparameters used in the paper are defined in the `default_config()` function in `main_MDP.m`.
